# Masalah
- Musyawarah perencanaan pembangunan (Musrenbang) masih mengharuskan kehadiran secara fisik yang menyebabkan banyak warga yang kesulitan untuk berpartisipasi dalam musyawarah tersebut.
- Pemerintah kesulitan untuk mengetahui rencana pembangunan mana yang memang berdampak dan berguna bagi masyarakat.
- Pemerintah kesulitan untuk mengetahui skala prioritas dari rencana pembangunan yang mana hal ini disebabkan oleh proses rekapitulasi usulan dari kelurahan ke kecamatan masih dilakukan secara manual. 

# Pelaku
- Warga masyarakat
- Staff di tingkat kelurahan, pemerintah tingkat kecamatan, dan Bappeda.

# Proses Bisnis
Musrenbang d tingkat kecamatan, dari usulan warga, verifikasi di kelurahan, sampai rekapitulasi prioritas di kecamatan dan Bappeda
